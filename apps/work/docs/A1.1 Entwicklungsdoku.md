# Work A1.1 – Entwicklungsdoku (OnePager)

**Stand:** 04.11.2026 · **Basis:** A1.0 (produktiv) · **Teil von:** Bilderwerk View · **Details:** `docs/Work Dokumentation.md`

## Ziel
Den Work aufräumen, dokumentieren und so erweitern, dass er **Vorschaubilder in die Katalog-DB** schreibt und **regelmäßig über das ganze Archiv (≈ 81.000 Bilder)** laufen kann – Wiederholungsläufe in Stunden statt Monaten.

## A1.1c – Erweiterungen
| Thema | Umsetzung |
|---|---|
| **Vorschaubilder** | Tabelle `vorschauen` (Schlüssel = `bilder.hash`, Duplikate teilen sich eine); JPEG ≤ 640 px, Q80, EXIF-Drehung angewendet, ohne Metadaten, Transparenz → weiß; im selben Commit wie der Eintrag; Fehler blockieren den Eintrag nicht |
| **Schema 4** | Migration 2→3→4 beim Öffnen, Daten unverändert, DB wird nie gelöscht; unbekannte Version → Abbruch ohne Änderung |
| **Wiederholungslauf** | Bestand einmal in den Speicher; unverändert (Pfad+Größe+mtime) → nur fehlende Vorschau ergänzen; neu/geändert → analysieren |
| **Entfernte Bilder** | nur nach vollständigem Lauf und nur unter dem gewählten Ordner; verschobene Dateien behalten die KI-Analyse (Duplikat rückt zum Original auf); Schutz: > 25 % fehlend → nichts löschen (`--entfernen-erzwingen`) |
| **Dropbox „nur online“** | Platzhalter werden für Vorschauen nicht geladen, sondern gezählt; PDF-Seitenzahl unveränderter PDFs aus der DB |
| **Sicherung** | Standard alle 1.000; in der GUI während des Laufs änderbar; Abschlusssicherung immer (auch bei Stopp), protokolliert, fehlertolerant |
| **GUI** | DB-Status live (Einträge, Vorschauen, Uhrzeit); Zähler „Vorschau ergänzt“, „Nur online“, „Entfernt“ |
| **Tool** | `tools/vorschau_nachholen.py`: Vorschauen ohne LM Studio, fortsetzbar, `--limit`, `--nur-ordner`, `--neu`, `--auch-online`, `--backup` |

## Betrieb
- Python: Homebrew `python3.14` mit `pillow`, `numpy`, `python-tk@3.14` (nach `brew upgrade` prüfen)
- Bestand nachrüsten: `python3.14 tools/vorschau_nachholen.py --db <DB> --backup <Sicherung>`, danach einmal `VACUUM`
- Wiederholungslauf: denselben Ordner erneut starten (GUI oder `katalog.py`)
