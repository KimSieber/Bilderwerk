# PictureSearchView v0.0.1 – Grundgerüst und Suche

**Datum:** 03.11.2026 · **Stufe:** 1 von 6 · **Status:** lauffähig, getestet mit 23.742 Bildern

## Ergebnis
Eigenständige macOS-App (Tauri 2), die die Sicherungskopie des KI-Bildkatalogs nur lesend
öffnet und kombinierbar durchsucht. Antwortzeit 10–150 ms. Start auf leerer Fläche, nur mit Suchfeld.

## Umgesetzt

| Bereich | Inhalt |
|---|---|
| **Architektur** | Tauri 2 · React 19 + TypeScript (Vite) · Rust-Kern mit `rusqlite` (SQLite eingebaut, FTS5) – Konzept: `docs/Technologie- und Architekturkonzept.md` |
| **Datenbank** | `mode=ro&immutable=1`: keine Schreibzugriffe, keine Sperren, keine WAL-Dateien in Dropbox; Prüfung auf Katalog-Tabellen |
| **Freitext** | FTS5-Trigram über Ablage, KI-Text, Metadaten + Archiv-Wurzel · Wortteile (`boot` → `Boote`) · `"Phrase"` · `-Ausschluss` · Begriffe < 3 Zeichen per Teilstring |
| **Kriterien** | Dateiname, Ordner, Datum von/bis (`JJJJ[-MM[-TT]]`), Dateityp-Gruppen, Duplikate ein/aus – alle mit UND verknüpft |
| **Sortierung** | Datum absteigend; unplausible Daten (z. B. `2056-55-10`) und fehlende ans Ende; max. 3.000 Treffer + Gesamtzahl |
| **Oberfläche** | Suchfeld gleitet bei Treffern nach oben, aufklappbare Kriterien, Trefferliste, hell/dunkel nach System |
| **Bedienung** | ⌘F Suchfeld · Esc leeren · ↑/↓ Auswahl · Bild↑/↓ blättern · Pos1/Ende |
| **Einstellungen** | DB-Pfad je Rechner (`~/Library/Application Support/…/einstellungen.json`), DB-Menü mit Stand der Sicherung |
| **Lokale Werte** | `psv.local.json` (nicht im Repo) liefert über `build.rs` den DB-Vorschlag; Vorlage `psv.local.example.json` |
| **Sonstiges** | App-Icon (SVG-Vorlage + alle Größen), README, `.gitignore`, Dropbox-Ausschluss für `node_modules`/`target` |

## Erkenntnisse
- Katalog enthält unplausible Aufnahmedaten aus Dateinamen → Korrektur gehört in `metadaten.py` (Bildkatalog).
- Ordnernamen der Archiv-Wurzel (z. B. „2012-06-09 Hochzeit …“) stehen nicht im FTS-Index → zusätzlich per Teilstring durchsucht.
